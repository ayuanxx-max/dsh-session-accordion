# DSH 会话管理指南：折叠与分叉树

> 面向「会话一多就找不着」的 DSH 用户。两个纯客户端插件，不改核心，装上即用。

## 1. 问题

- 一个任务动辄几十轮，侧边栏/对话区被撑得很长；
- 用 fork 做分支实验后，子会话和父会话在列表里平铺，看不出血缘；
- 想回看「上周那个问题怎么解决的」，要翻很久。

## 2. 两个插件

| 插件 | 解决什么 | 交互 |
| --- | --- | --- |
| `dsh-session-accordion` | 每轮对话压成一行（时间胶囊 + 问题摘要） | 点一下展开，只保留最新一条展开 |
| `dsh-session-fork-tree` | 分叉会话挂到父会话下面 | 圆角导轨 + 绿色展开器 + 祖先链高亮 |

## 3. 安装

```jsonc
// ~/.dsh/profiles/desktop/package.json
"dsh": { "profile": { "bundles": [ ... , "dsh-session-accordion", "dsh-session-fork-tree" ] } }
```

完全退出 DSH 后重新启动。

## 4. 组合用法（推荐）

1. 用 **fork** 开分支实验（同一个问题试三种方案）；
2. 用 **fork tree** 一眼看清哪几个分支来自同一个父会话；
3. 用 **accordion** 把每个分支的历史压成单行，只展开正在看的那条；
4. 做完实验，把没用的分支归档，主干继续保持短。

## 6. 常见问题

| 问题 | 处理 |
| --- | --- |
| 装上没反应 | 确认包名在 `dsh.profile.bundles`，且完全退出后重启 |
| 折叠后找不到旧内容 | 点击时间胶囊展开；摘要来自该轮第一个问题 |
| 分叉树显示平铺 | 确认 fork 关系存在（同一父会话派生）；刷新会话列表 |
| 与其它 UI 插件冲突 | 先在 `cordis.patch.yml` 里单独禁用另一个插件定位 |
