## 3. P2（收口项，不影响主流程）

- 行级快速跳过只看 `parts.rest[0]`（`1741-1748`）：React 只重挂第二个 `rest` 节点时，新节点漏打 `data-ac-hidden`，表现为折叠行里露出一块正文，且不会自愈。
- `data-ac-pinned="0"` 常驻、scroll host 的 `data-ac-pos` + 行内 `position:relative`、`<html>` 的 `data-ac-theme` 在停止后都不回收。
- `role="button"` 在**展开态**也挂着（`1753-1758`），把整段提问从无障碍树里摘掉（只留 `aria-label` 的前 60 字）。
- `dsh-ac-mem:*` 一会话一键、不会自动清理；配额满后静默退化为内存 Map，用户以为记住了其实没存。
- 搜索输入未处理 IME（`compositionstart/end`），拼音过程中列表会闪空。
- RTL / forced-colors / `color-mix` 回退：定位全用物理方向，强制高对比下折叠行的箭头（`background-image`）会消失。
- `__acConfig({timeline:false})` 后日期头要等下一次布局签名变化才消失（`layoutSignature` 不含配置位）。
- 守卫补丁（withdraw guard）装上是单向的：原文未保存、`guard:false` 运行时不生效、`events.subscribe` 不退订。

## 4. 审计确认"干净、别动"的部分

1. 插件**从不写 `scrollTop`**（6 处全是读），程序化滚动只出现在用户主动的 `j/k` 与搜索回车。
2. 滚动/滚轮/touch 监听全是 `passive`，没有任何滚动路径上的 `preventDefault`。
3. `schedule()` 的 rAF 去重是真的（`pending` 标志），`schedulePinFix` 每次重排前都会取消上一个 rAF 与定时器。
4. 90 ms 滚动期量测上限有效；滚停后约 40 ms 有一次不设限的精确校正。
5. 观察器只订阅 `childList`（不含 `attributes`/`characterData`）→ 插件自己的属性写入不会自激；`applyDepth` 挡住了日期头插入的回环。
6. 行内状态全走 `setAttr` 相等即跳过，没有逐行 style 写；`stampCache`/`restCache`/`timeCache` 都是 `WeakMap`，不产生节点滞留。
7. 折叠用 `visibility`（保布局盒）而不是改高度，展开/收起不会引起滚动条抖动；`prefers-reduced-motion` 已处理。
8. 所有 `localStorage` 访问（包括属性访问本身）都包了 try/catch，并有内存 Map 兜底。
9. `insertBefore` 前有 `parentNode` 校验、删除有 `used/父节点` 双重校验；克隆气泡失败会退回纯文本。

## 5. 修复顺序（建议）

**阶段 1 — P0（先做，收益最大、回归面可控）**
1. 逻辑：`trackExpanded` 出口加一条"目标必须存在于当前 `ids`"，并让 `saveMem()` 只在 id 有效时落盘（修 #1）。
2. 性能：`DBG` 读取全部收进 `dbgOn` 守卫（修 #2）；采样器保存 rAF 句柄并在 `stop()` 取消（修 #3）；观察器同步路径改为"仅新增行同步，其余一律 rAF"（修 #4）。
3. 验证：三场景 + 新增一条断言 `switch-from-1-turn`（1 轮会话 ↔ 多轮会话互切，要求"最新一条展开"且旧记忆不被覆盖）。

**阶段 2 — P1 功能与鲁棒性**
5→6→7→8→13→12（搜索状态、Esc 还原、`stop()` 全量回收、`safeApply`、`noteScroll` 短路、`syncPins` 脏检查），再做 9/10/11（键盘收口、start 延迟到 body、单例守卫）。

**阶段 3 — P2 收口**：无障碍只在折叠态、存储清理与配额告警、IME、RTL/forced-colors。

## 6. 复现要点（P0 #1）

1. 会话 B 只发一条消息（1 轮），确认它是展开的。
2. 侧栏切到一个 ≥3 轮、且之前停在中间某轮的会话 A。
3. 现象：A **全部折叠、一条都不开**；`__acReport().expandedId` 指向 B 的 turn id。
4. `localStorage['dsh-ac-mem:…A…']` 里的 `expanded` 已被写成 B 的 id（数据丢失）。
